QU'EST-CE QUE C'EST

GitHub Pages

Un service d'hébergement gratuit qui permet de publier des sites web directement depuis un dépôt GitHub.

  • Hébergement statique 100% gratuit
  • Déploiement automatique à chaque push
  • Support des domaines personnalisés
  • HTTPS inclus par défaut
  • Idéal pour portfolios et documentations
PRÉREQUIS

Avant de Commencer

  • Un compte GitHub (gratuit)
  • Un projet avec un fichier index.html
  • Git installé (optionnel, pour la ligne de commande)
  • Connaissances de base en HTML/CSS
ÉTAPE 1

Créer un Dépôt

1

Connexion

Allez sur github.com et connectez-vous à votre compte

2

Nouveau dépôt

Cliquez sur le bouton "+" puis "New repository"

3

Nommer

Donnez un nom significatif à votre projet

4

Créer

Cliquez sur "Create repository" pour continuer

ÉTAPE 2

Ajouter les Fichiers

Option A: Navigateur

  • Cliquez sur "uploading an existing file"
  • Glissez-déposez vos fichiers
  • Validez avec "Commit changes"
ÉTAPE 2

Option B: Ligne de commande

git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/user/repo.git
git push -u origin main
ÉTAPE 3

Activer GitHub Pages

1

Paramètres

Cliquez sur l'onglet "Settings" du dépôt

2

Pages

Dans le menu latéral, sélectionnez "Pages"

3

Source

Sous "Build and deployment", choisissez "Deploy from a branch"

4

Branche

Sélectionnez "main" et "/ (root)", puis sauvegardez

RÉSULTAT

Votre Site est En Ligne

Après activation, votre site est accessible à cette adresse :

https://username.github.io/repository-name
  • Attendez 1-2 minutes pour la mise en ligne
  • Vérifiez la progression dans l'onglet "Actions"
  • Chaque push redéploie automatiquement
