🌐 C'est quoi une adresse IP ?

Définition simple

Une adresse IP (Internet Protocol) est un identifiant numérique unique attribué à chaque appareil connecté à un réseau.

  • Votre PC, smartphone, serveur, caméra IP…
  • Permet d'envoyer et recevoir des paquets
  • Fonctionne comme un numéro de maison

📮 ANALOGIE

Réseau = rue  |  IP = numéro de porte

📦 COMMENT ÇA MARCHE ?

Toute communication réseau est découpée en paquets. Chaque paquet porte l'IP source et l'IP de destination.

💡

Sans adresse IP, les appareils ne pourraient pas se "retrouver" sur un réseau, qu'il soit local ou mondial.

CIDR (Classless Inter-Domain Routing) — La notation /24 signifie que les 24 premiers bits identifient le réseau. Plus le nombre est grand, moins il y a d'hôtes disponibles.

🧮 Mécanique du Masque

Comment le système sait si une IP est dans le même réseau ? L'opération ET (AND) bit à bit entre l'IP et son masque.

Binaire de l'IP

11000000.10101000.00000001.00001010

Binaire du Masque (/24)

11111111.11111111.11111111.00000000

Résultat (Réseau)

11000000.10101000.00000001.00000000

→ 192.168.1.0

⚡

Le routeur compare les résultats. Si deux machines ont le même résultat "Réseau", elles sont voisines !

✂️ Exemple Concret de Subnetting

Scénario : Une entreprise possède le réseau 192.168.1.0/24 et veut le diviser en 4 sous-réseaux.

Solution : utiliser un /26 → 4 sous-réseaux de 62 hôtes chacun

Sous-réseauAdresse réseauPlage hôtesBroadcast
SR 1 192.168.1.0/26 192.168.1.1 – .62 192.168.1.63
SR 2 192.168.1.64/26 192.168.1.65 – .126 192.168.1.127
SR 3 192.168.1.128/26 192.168.1.129 – .190 192.168.1.191
SR 4 192.168.1.192/26 192.168.1.193 – .254 192.168.1.255
⚡

Règle : adresse réseau (non assignable) + broadcast (non assignable) = toujours 2 adresses perdues par sous-réseau. D'où 2ⁿ − 2 hôtes.

🔢 IPv4 vs IPv6

IPv4

Actuel
192.168.1.1
  • 32 bits → 4,3 milliards d'adresses
  • Format décimal pointé
  • Le plus utilisé aujourd'hui
  • Pénurie depuis ~2011
📌

C'est le protocole que vous utilisez sur votre réseau local (Wi-Fi, Ethernet).

IPv6

Futur
2001:0db8:85a3::8a2e:0370:7334
  • 128 bits → 3,4 × 10³⁸ adresses
  • Format hexadécimal (groupes de 16 bits)
  • Conçu pour remplacer IPv4
  • Sécurité intégrée (IPsec)
🚀

Assez d'adresses pour attribuer 670 quadrillions d'IPs par mm² de la Terre !

✨ Adresses Spéciales

Certaines IPs ont des rôles réservés que vous ne pouvez pas utiliser normalement.

Adresse Nom Rôle
127.0.0.1 Loopback L'ordinateur lui-même ("moi-même")
0.0.0.0 Wildcard Toutes les interfaces disponibles
192.168.1.255 Broadcast Message à TOUS les hôtes du réseau
192.168.1.0 Adresse Réseau Identifie le réseau lui-même (non assignable)
169.254.x.x APIPA Attribution auto quand le DHCP échoue
🔁

Astuce : ping 127.0.0.1 — si ça répond, votre carte réseau est fonctionnelle, même sans connexion.

📊 Les Classes d'IP (Système Legacy)

Avant le CIDR, les IP étaient divisées en classes fixes. Ce système est dépassé mais encore enseigné.

Classe Début (1er bit) Plage Hôtes max Usage
A 0xxxxxxx 1.0.0.0 → 126.x.x.x 16 millions Très grands réseaux
B 10xxxxxx 128.0.0.0 → 191.x.x.x 65 534 Réseaux moyens
C 110xxxxx 192.0.0.0 → 223.x.x.x 254 Petits réseaux (LAN)
D 1110xxxx 224.0.0.0 → 239.x.x.x — Multicast
E 1111xxxx 240.0.0.0 → 255.x.x.x — Réservé (expérimental)
⚠️

Aujourd'hui on utilise CIDR (Classless) pour plus de flexibilité. Les classes A-E sont considérées comme obsolètes en pratique.

⚙️ DHCP vs IP Statique

🤖 DHCP

Dynamic Host Configuration Protocol

Le routeur attribue automatiquement une IP à chaque appareil qui se connecte.

  • Aucune configuration manuelle
  • IP peut changer à chaque connexion
  • Idéal : PC, smartphone, tablette
# Renouveler son IP (Windows)
ipconfig /release
ipconfig /renew

📌 IP Statique

Configurée manuellement par l'admin

L'adresse IP ne change jamais. Essentiel pour les équipements qui doivent toujours être trouvables.

  • Adresse fixe et prévisible
  • Nécessite configuration manuelle
  • Idéal : serveurs, imprimantes, caméras
💡

Un serveur web doit avoir une IP statique — sinon les utilisateurs ne pourraient jamais le retrouver !
